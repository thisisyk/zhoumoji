# 美团笔试｜周末集

[打开在线原型](https://thisisyk.github.io/zhoumoji/)

面向杭州下沙大学城的周末兼职撮合原型。学生可以按校区、类别、日期和结算方式找岗位，收藏意向岗位、选择班次并跟踪报名。商家可以发布岗位、录用报名者和控制招募状态。

## 体验流程

1. 在「找兼职」选择岗位和班次，确认报名。重叠班次会提示冲突。
2. 在「商家入口」打开该岗位的「管理报名」并录用，再到「我的报名」查看结果。
3. 在商家工作台发布一个新班次，回到「找兼职」按名称搜索。

岗位使用示例数据，报名、收藏和新发布的岗位保存在当前浏览器。页面使用原生 HTML、CSS 和 JavaScript，静态部署，无需安装依赖。

## 更新

GitHub Pages 从 `main` 分支根目录发布。修改 `index.html`、`styles.css`、`app.js` 或 `assets/` 后提交到 `main` 即可更新原链接。
